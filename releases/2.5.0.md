# Axeptio Android SDK - Version 2.5.0 Release Notes

**Release Date:** September 02, 2026
**Package:** `io.axept.android:android-sdk:2.5.0`

---


### Added

- **store:** expose cmpRestoredEventCount on AxeptioStore
- onConsentSaved callback after popup consent persistence (android-q37)

### Changed

- **release:** set VERSION_NAME to 2.4.0 [skip ci]
- back-merge master into develop
- document codeless app attribution partner consent forwarding

### Fixed

- **cmp:** stop reporting a widget failure as a restored consent
- **cmp:** fire onCMPRestored on the path the widget actually uses
- **cmp:** make popupRequestedThisCycle volatile
- throw IllegalStateException from consent getters before initialization
- replay onConsentCleared to the first listener registered after an unobserved clear
- drop the in-memory client token on clearConsents()
- replace corrupt event datastore files with their empty defaults
- cap event queue at 500 events with oldest-first eviction
- drop consent proofs with no configuration id and surface delivery failures
- serialize widget bridge events off the JS thread on a supervised scope
- gate popup display on validated network instead of any active network
- log and notify listeners when showConsentScreen is suppressed
- replace webview probe interceptor with onReceivedHttpError
- tear down the cmp dialog when its host activity is destroyed
- release the popup webview when the cmp dialog is destroyed
- re-show the cmp popup on the recreated activity after a configuration change
- add safe service slug lookup and reject unsupported preference store types
- count partial days when computing remaining consent days
- make listener notification thread-safe and isolate throwing listeners
- omit adjust eea granular option when gdpr applicability is unknown
- return null token instead of empty string before cmp popup has run
- correct the clearConsent deprecation message to name the ios alias
- report non-uncaught console errors without tearing down the cmp popup
- let cached brands consent satisfy the popup display gate offline
- skip singular init when the sdk secret is not configured
