# Axeptio Android SDK — 2.2.0-beta.1

> **Beta release** — not recommended for production use.

## Breaking Changes

- **Kotlin-only SDK**: Java language support has been dropped. The `samplejava` sample module is removed.
  - `AxeptioSDK.instance()` and `AxeptioAPIRepository.instance()` no longer expose `@JvmStatic` companions.
  - **Migration:** replace `AxeptioSDK.instance()` with `AxeptioSDK.INSTANCE.instance()`, or migrate your consumer to Kotlin.
  - Consumers compiled against earlier versions may encounter `NoSuchMethodError` at runtime — recompile against this release.

## New Features

- `onError(message: String)` callback on `AxeptioEventListener` for SDK-level error notifications.
- `getRemainingDaysForConsent()` — query the number of days until the current consent expires.
- `setForceShowConsentDebug()` — force-display the consent popup; useful for QA and debug builds.
- `setDisplayPopUpOnEnterForeground()` — control whether the consent popup appears when the app returns to the foreground.
- `AxeptioStore` — Jetpack Compose-friendly `StateFlow`-based event store for reactive UI integration.
- Public API naming aligned with iOS SDK conventions for a consistent cross-platform developer experience.

## Bug Fixes

- Nullable `$$date` field in consent cookie is now handled safely — no more `NullPointerException` on missing or blank dates.
- Replaced broad `Exception` catch blocks with specific `JsonDataException`, `JsonEncodingException`, and `DateTimeParseException` handlers in consent expiry use cases; errors are now logged via `Log.e`.
- Fixed `Int` overflow in `days * 24 * 60 * 60` — updated to `days.toLong() * 86_400L` in `HasConsentExpiredUseCase` and `GetRemainingDaysForConsentUseCase`.
- `HttpURLConnection` is now properly closed in `shouldInterceptRequest`, preventing socket/file-descriptor leaks.
- Fixed incorrect `Int` null fallback for the `IABTCF_EnableAdvertiserConsentMode` shared preference.
- Removed detekt baseline suppressions for `SwallowedException`/`TooGenericExceptionCaught` in consent use cases.
- CMP dialog now auto-dismisses on uncaught WebView JavaScript errors, preventing the consent popup from getting permanently stuck when the hosted React app crashes.

## Installation

```kotlin
// settings.gradle.kts
maven {
    url = uri("https://maven.pkg.github.com/axeptio/axeptio-android-sdk")
    credentials {
        username = System.getenv("GITHUB_ACTOR")
        password = System.getenv("GITHUB_TOKEN")
    }
}

// build.gradle.kts (app module)
implementation("io.axept.android:android-sdk:2.2.0-beta.1")
```
