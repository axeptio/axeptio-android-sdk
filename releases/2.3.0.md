# Axeptio Android SDK - Version 2.3.0 Release Notes

**Release Date:** June 25, 2026
**Package:** `io.axept.android:android-sdk:2.3.0`

---


### Added

- foundation for App Attribution Partner consent forwarding (android-6te)
- AppsFlyer consent forwarder (android-cod / MSK-185)
- Adjust consent forwarder (android-o8a / MSK-186)
- forward Google consent to Singular (codeless, MSK-187)
- forward Google consent to Firebase Analytics (codeless, MSK-188)
- **sample:** AAP test environment for App Excellence demo video

### Changed

- merge master back into develop after 2.2.0 release
- clarify initializeConsentForwarding build/replay semantics
- note AdjustThirdPartySharing ctor is boxed Boolean (verified vs Adjust SDK)
- use GoogleConsentType.entries in FirebaseConsentMapper
- **events:** address Copilot review on the atomic drain (S2-4)

### Fixed

- address Copilot review on AAP consent forwarding foundation
- clear persisted Google consent on clearConsents() (privacy)
- address Copilot review on AppsFlyer forwarder
- **sample:** escape Singular secret for the generated BuildConfig literal
- **sample:** catch Singular (and Firebase) in aap-capture.sh consent filter
- **android:** harden lifecycle & network callback against crash and Activity leak
- **android:** track current Activity from onActivityStarted too
- **android:** make Google consent parser total against malformed payloads
- **android:** reject re-initialization with a different targetService
- **widget:** persist consent before tearing down the dialog (S2-3)
- **events:** atomic, serialized event-queue drain (S2-4)
- **proguard:** keep reflective Moshi models + partner classes in consumer rules (S2-7)
- **proguard:** keep Firebase nested ConsentType/ConsentStatus enums (S2-7)
- **proguard:** unconditional -keep for reflected partner classes (S2-7)
- **proguard:** keep parameter annotations for reflective Moshi; drop redundant rule (S2-7)
- **proguard:** drop no-op @Json-fields keepclassmembers rule (S2-7)
- **forwarding:** log when a partner SDK is present but incompatible (S2-6)
- **forwarding:** also warn when a partner class is present but fails to link/init (S2-6)
- **widget:** re-check state before deferred show; drive load timeout off progress (S2-1, S2-10)
- **widget:** guard timeout re-arm after destroy and listener removal on dead observer (S2-1, S2-10)
- **events:** stop replaying stale Google consent to every new popup (S2-5)
- **events:** deliver listener callbacks on the main thread (S2-8)
- **widget:** suppress phantom onPopupClosedEvent on config change (S2-2, partial)
- **webview:** confine the JS bridge to first-party origins; guard external launches (S2-9)
- **webview:** only redirect main-frame navigations; fail closed on null request (S2-9)
- **webview:** gate external launches on a user gesture; require a real host (S2-9)
- **webview:** normalize URI scheme/host with Locale.ROOT (S2-9)
- **webview:** first-party in-WebView navigation is https-only (S2-9)
